泛化鸿沟：
AI 感知 vs SQL 逻辑。

SAP、Oracle、ERPNext 等 ERP 系统要求完美和严格的数据结构，而仓库供应链的现实却杂乱无章。供应商版式一变，传统的区域 OCR 就失效。ERPYAS 把 AI 认知提取与确定性的交易会计彻底分开，跨越了这道鸿沟。

快速开始（约 5 分钟）

我是新用户，该从哪里开始？

第 1 步：您已经在用 ERPNext 了吗？ 太好了，直接看第 3 步。

第 2 步：还没有 ERPNext？几分钟就能开通。 ERPNext 是免费开源的 ERP（会计、采购、销售、库存等），深受成千上万企业信赖。它的开发者 Frappe 为您托管：快速、可靠、自动备份和升级。您只需支付托管费用（查看 Frappe 价格）：

  • 每月 $20 起（Servers）：⭐ 强烈推荐用于 ERPYAS。 您拥有自己的虚拟服务器，ERPYAS 有足够的资源快速、可靠地读取您的物料和科目并过账发票。
  • 每月 $125 起：面向大企业的高级独享服务器。同样完全支持。
  • 每月 $5 起（Sites，共享服务器）：ERPYAS 不支持。 适合手动试用 ERPNext，但不适合 ERPYAS（见下方“该选哪个 ERPNext 套餐？”）。

在 frappe.io/erpnext 点击 Start free trial，然后在设置向导中创建您的公司。（价格由 Frappe 制定，可能变动。）

第 3 步：获取 ERPYAS 应用。 在本页点击 申请 TestFlight / APK 试用版，即可获得 Android 应用（APK）。Google Play：即将上架。

第 4 步：快速设置（约 5 分钟）。

  1. 打开 ERPYAS，点击 Continue with Google。
  2. 在 ERPNext 中打开您的 User 资料 → API Access → Generate Keys。把这个用户的语言设为英语（其他人可以用任何语言）。
  3. 在 ERPYAS 中输入您的 ERPNext 地址（例如 yourcompany.frappe.cloud）、API Key 和 API Secret，然后点击 Connect。
  4. 输入邀请码开始 7 天免费试用（10 张发票），或选择一个套餐，然后扫描您的第一张发票。
ERPYAS 应该选哪个 ERPNext 套餐？

我们强烈推荐 Frappe Cloud 每月 $20 的 Servers 套餐（或更高）。 每月 $5 的 Sites 套餐不支持 ERPYAS。

  • 原因：每次扫描时，ERPYAS 都要读取您的物料、供应商和科目，并在 ERPNext 中创建带附件的草稿；CEO 模式还会读取您的整个账簿。$5 套餐让您的站点与其他客户运行在共享服务器上，繁忙时这些请求可能变慢、受限或超时。
  • $20 或更高套餐的好处：独享服务器资源，扫描和报表更快，上传失败更少，尤其是在物料成千上万或每天发票很多时。
  • 已经在用 $5 套餐？ 请先在 Frappe Cloud 控制台升级，再连接 ERPYAS。由 $5 套餐限制引起的问题不在 ERPYAS 支持范围内。
  • 自建服务器？ 目前不支持：ERPYAS 只连接 Frappe Cloud 和 ERPNext Cloud 上的站点。如使用其他托管方，请联系我们。

（价格由 Frappe 制定，可能变动：查看 Frappe 价格。）

我的 ERPNext 有多家公司，ERPYAS 用哪一家？

您选的那家。 在首页或 CEO 模式中点击公司标签，或进入 设置 → 公司，从您 ERPNext 中的公司里选择。

  • 扫描的发票过账到该公司，付款页面显示它的科目，CEO 模式报告它的账目。
  • 每个人在自己的手机上选择，随时可以更改。在此之前，ERPYAS 使用您 ERPNext 的默认公司。
  • 已在发件箱中等待的发票，保留扫描时所选的公司。

  2. 输入您的 ERPNext 地址（例如 yourcompany.frappe.cloud）以及 ERPNext 的 API Key 和 API Secret。
  3. 点击 Connect。ERPYAS 检查连接后，就可以开始扫描了。

有邀请码？ 在 设置 → 账户和套餐 → 邀请码 中输入，即可开始 7 天免费试用，含 10 张发票和 CEO 洞察。无需银行卡。没有邀请码？请在 www.erpyas.com 选择套餐。

ERPNext 的 API Key 和 Secret 从哪里获取？

在 ERPNext 中：打开您的 User 资料 → API Access → Generate Keys。- 使用一个有权创建采购发票、并能读取供应商、物料和科目的用户。ERPYAS 只会创建一个供应商，而且只创建一次：Unknown_supplier。- 把这个用户的语言设为英语（User → Language）。ERPNext 中的其他人可以用任何语言。ERPNext 用这个用户的语言写系统消息，ERPYAS 会读取这些消息来自动修正小的拒绝问题。- ERPNext 只显示一次 Secret，请直接复制到应用中。

我们在 ERPNext 中必须用什么语言？

任何语言都可以。 您的会计和员工可以用中文、印地语、阿拉伯语、德语、英语或其他任何语言使用 ERPNext，ERPYAS 应用也可以用另一种语言。只有其 API 密钥填在 ERPYAS 中的那个用户需要设为英语。供应商、物料和科目名称完全保持您输入的样子。ERPYAS 写在草稿上的内容保持英文（Printed supplier、Unknown_supplier、标签“ERPYAS Review”），因为 ERPYAS 会读回这些内容来学习您的供应商并识别重复。

需要在 ERPNext 中安装什么吗？

不需要。 无插件、无自定义代码、无需改动服务器。ERPYAS 使用 ERPNext 标准、安全的 API。

什么会消耗额度？

AI 读取的每份单据消耗一个额度：- 成为 ERPNext 草稿的发票，- 读取后发现的重复（例如对 ERPNext 中已有发票重新拍照），- 读取后未被接受的单据（不是发票、手写、无法识别）。

以下免费：- 再次发送同一文件（在 AI 读取前就能识别），- 我方出错，或 Gemini / ERPNext 不可用，- ERPNext 拒绝草稿（例如您的设置中缺少科目），- 网络中断后重新发送同一上传。

撤销发票后额度会退回吗？

不会。24 小时撤销（见第 6 节）会删除草稿，让您可以重新扫描，但已用额度不退还，因为发票已经被读取。上传失败和再次发送同一文件从不消耗额度。

ERPNext 中会出现什么？

ERPYAS 具体会创建什么？
  • 一张采购发票草稿，包含供应商、发票号、日期、每一行明细、折扣和税费。
  • 附上原始发票文件，审计人员一键即可查看原件。
  • 草稿的总额始终与发票总额一致。
它会帮我创建供应商和物料吗？

不会，绝不会。 您的供应商列表和物料目录完全保持原样。ERPYAS 只有在 100% 确定时才会选择已有记录：

  • 物料：只有当印刷的编码与某个物料的编码、条形码、制造商零件号或供应商零件号完全一致时才会关联（标点和空格不影响，所以 LAV-DSP-86T = LAVDSP86T），或名称完全相同。否则该行保留印刷的名称和描述，不关联物料。您可以稍后在应用中关联。
  • 供应商：只有在增值税 / GST 号相同、名称相同，或您的会计以前为这个印刷名称做过选择时才会使用。其他情况，即使 95% 相似或是新供应商，都会使用占位供应商 Unknown_supplier，并暂扣草稿，草稿上会注明印刷的名称、税号和最接近的供应商。您也可以在应用的“供应商”按钮上自己选择供应商（本公司最常用的 10 个，或搜索全部已启用的供应商）：完全按您的选择使用，仅用于那一次上传。
  • 批量上传过程中不会询问任何问题。完成后，一个窗口按供应商把草稿分组，点一下就能修正该供应商的所有草稿（“接受全部建议”、“全部新建”）。
税费、运费和折扣如何处理？
  • 明细行按印刷内容记录。
  • 整单折扣记录为折扣。
  • 增值税 / 销售税、运费和类似费用记为一行税费。

这样草稿与发票金额完全一致。

已付还是未付？

扫描前由您选择，一次选择适用于整批：- 赊账（稍后付款）：草稿记入应付账款。- 现金或银行：记为已从您选择的账户付款。

使用哪个费用科目？
  1. 您选择的科目，在扫描按钮上方的借方标签中选择。
  2. 借方（自动）（未选择）使用 ERPNext 自己的默认设置：关联到您某个物料的行使用该物料的默认科目；其他行使用您公司的 Default Expense Account。如果您的公司没有设置，ERPYAS 会使用一个费用科目并暂扣草稿，告诉您如何设置默认科目。

没有暂记科目：每一行都记到真实的科目上。

“暂扣待审”是什么意思？（没有暂记科目。）

当某些内容需要人来决定时，草稿保留真实科目，并打开 ERPNext 自带的 Hold Invoice 开关，原因写在草稿上。例如：- 明细合计与印刷总额不符，- 供应商不确定（Unknown_supplier），- 日期或总额无法识别。

在应用中（点击发件箱里的发票）或在 ERPNext 中打开它，按备注修正，解除暂扣，然后照常审批。

供应商发来更正版发票怎么办？

ERPYAS 能识别：- 如果原发票仍是草稿，则更新该草稿。- 如果原发票已提交，则创建新草稿并标记待审。

如何防止重复？

ERPYAS 会阻止同一张发票出现两次，无论是：- 同一文件，- ERPNext 中已有相同供应商和发票号，- 还是再次扫描的相同发票内容。

重复时显示“已拦截重复”。再次发送同一文件免费；如果 AI 必须读取发票才能发现重复，则消耗一个额度。

会计的日常流程

  1. 发票一到就扫描（一张一张或每批最多 50 张）。
  2. 打开 ERPNext → Buying → Purchase Invoice，按 Draft 筛选。
  3. 对照附件原件审核每张草稿。先看被暂扣的草稿，备注会说明原因。
  4. 提交。ERPYAS 从不提交、付款或删除已提交的单据。这始终由您决定。
扫错了发票，能撤销吗？

可以，在 24 小时内：1. 点击底部栏的发件箱，打开24 小时紧急撤销，点击发票旁的撤销，或回滚全部草稿。2. 草稿及其附件会从 ERPNext 中删除，您可以重新扫描。已用额度不退还，因为发票已被读取。3. 已经提交或付款的发票受到保护，永远不会被删除。

可以在多部手机上使用 ERPYAS 吗？

可以。在每部手机上用同一个账户登录并连接同一个 ERPNext。额度、套餐和防重复保护是共享的，每张草稿都进入同一个 ERPNext。在发件箱中点击所有手机，可查看过去 30 天 ERPYAS 从每部手机放入 ERPNext 的内容，以及它们在 ERPNext 中的当前状态（草稿、暂扣待审、已提交、已取消）。列表实时从您的 ERPNext 读取，ERPYAS 不保留副本。仍在等待上传的发票和 24 小时撤销，只保留在扫描它们的那部手机上（本机）。

仓库里没信号？

继续扫描。发票在应用的发件箱中等待，恢复联网后自动上传，就像 WhatsApp 消息一样。

老板与 CEO：CEO 模式

什么是 CEO 模式？

老板真正关心的问题，直接从您实时的 ERPNext 账簿中即时得到答案，就在手机上：- 利润表 - 资产负债表 - 现金流 - 现金流预测 - 谁欠我们钱（应收） - 我们欠谁钱（应付） - 营运资金 - 销售漏斗 - 预算与实际 - 分部利润

先选一个问题，再选期间：今天、1 个月、3 个月、6 个月或 1 年。

  • 利润、现金流、销售、预算和部门利润：该期间的合计。
  • 资产负债表、应收应付、营运资金：今天的数字，加上自期间开始以来的变化。
  • 现金预测：根据发票到期日，向前预测整个期间。

数字针对 ERPYAS 过账发票的那家公司（您 ERPNext 的默认公司）。

数字可信吗？

可信。AI 从不计算您的财务数字。每个数字都直接来自您的 ERPNext 账簿，使用标准会计报表，所以您看到的正是账上的数字。

账户、隐私与安全

几个人可以共用一个订阅吗？

订阅属于某一个人的 ERPYAS 账户（其 Google 登录）。每位负责扫描的团队成员都应有自己的账户和套餐。他们都可以过账到同一个 ERPNext 公司。

我的 ERPNext 密钥存在哪里？

只存在您的手机上，由手机的安全硬件密钥库加密。ERPYAS 服务器从不存储它们；每次请求时使用，用完即弃。

ERPYAS 会保留我的发票吗？

不会。 - 发票进入您自己的 ERPNext。- 批量上传只在处理期间短暂保存，并在 24 小时内自动删除。- 我们只保留运行您账户所需的信息：邮箱、套餐、额度余额和查重指纹（不是单据本身）。- 为了发现和修复问题：错误和崩溃报告（Error ID、应用版本、手机型号、Android 版本）。绝不包括您的发票、金额或 ERPNext 密钥。服务器日志保留 30 天，崩溃报告保留 90 天。

谁会处理这些数据？
  • Google Cloud 运行 ERPYAS（美国区域）。
  • Google Gemini AI 读取发票。
  • Firebase Crashlytics（Google）接收应用的崩溃报告。
  • Stripe 处理付款。

数据在传输过程中全程加密（HTTPS）。
